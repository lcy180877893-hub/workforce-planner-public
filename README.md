# 工程劳动力测算 · 公开稳定版候选 0.19.0-rc.1

独立于原私有测试服务。当前是已完成本地改造的候选版本，**尚未配置云端账户、实际部署或公开插件上架**。部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)，验收状态见 [RELEASE-STATUS.md](RELEASE-STATUS.md)。

## 使用方式

登录后使用四个页面：劳动力测算、比例设置、测算历史、工效库。公共工效库对所有已登录用户开放查看；只有服务器配置的管理员能修改。每个账号只能查询、读取、删除自己的测算历史。浏览器草稿、比例与内嵌界面状态也按账号区分。

施工判断继续由用户当前的 ChatGPT 会话进行，不调用模型 API、不要求模型 API 密钥。点击测算先准备工程资料，内嵌版通过宿主发送给当前会话，独立网页提供可复制的测算请求；连接**公开版**插件后，ChatGPT 先读取资料并确认缺失条件，再提交完整施工审查生成方案。网页本身不后台调用 ChatGPT，也不直接使用 ChatGPT 登录 cookie。

保留既有排程、劳动力柱状图、横道图及缩放。工期足够时优先顺序施工；不足时比较经审查允许的单班组白班搭接、多班组白班搭接、早晚班两套人员、多班组白班等适用方案，技术前置不会因赶工被取消。不自动补造工效或养护固定天数。

## 数据与安全边界

- 历史保存在 PostgreSQL，不依赖 Render 的临时本地文件。所有历史 SQL 都以服务器验证的用户身份限定，不接受工程量中的用户编号作为所有者。
- 用户身份由 Auth0 的 `iss + sub` 派生稳定标识；邮箱、名称、客户端角色字段不能提升管理员权限。网站使用 OIDC 安全 cookie，MCP 使用已验证的 OAuth Bearer，二者不互相回退。
- 网站写请求要求同源与 CSRF 校验；MCP 工具声明 read/write scopes，库维护还检查管理员权限。数据库连接强制验证 TLS 证书。
- 当前隔离采用服务端所有权检查，**不是 PostgreSQL RLS**。数据库连接凭据仅限服务端；不能直接给用户连接数据库。
- 同账号同 requestId 重试不重复保存；不同输入复用编号会拒绝。删除历史不会重置每日保存额度。
- 免费试运行保护：每用户最多保存 100 条、每天最多新增 20 条，全站最多 500 条，单方案最多 1 MiB。达到上限明确提示，不自动删除记录。项目最多 100 项、约 5 年；这些是本应用保护值，不是云厂商额度。

仅初始化代码中已随应用提供的默认工效，不读取、上传私有定制工效、私有删除名单、私有历史、隧道配置或密钥。初始化采用只插入缺项的方式，不覆盖管理员后续修改或恢复已删除条目。公开展示前仍须由管理员复核工效来源、适用范围与发布授权。

## 开发验证

使用 Node 24（`>=24.19 <25`）和锁定的 pnpm 11.25.0：

```text
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm preflight
```

测试用合成账号、离线签名 JWT、SDK 登录桩和 PGlite 执行 SQL，不使用真实私有记录或真实登录密钥。它们不替代部署后的 Auth0/Neon/ChatGPT 实测。

只有配置安全环境变量后才可运行 `pnpm migrate` 和 `pnpm start`；配置缺失时拒绝启动，不退回原私有文件存储。旧本地服务入口与模型 API 客户端未包含在本候选发布包中。仅 `productivity-store.js` 中的纯工效校验函数被云端复用，云端不会实例化其本地文件存储类。

## 免费方案限制

Render 免费 Web 服务空闲后会休眠，初次唤醒可能较慢；不承诺全天候可用。数据库使用独立 Neon Free，不使用会过期的 Render 免费数据库。Auth0 使用免费租户默认域名，不启用收费功能。超过任一提供商免费限额时先暂停或调整，不自动升级。详见 [Render Free](https://render.com/docs/free)、[Neon Pricing](https://neon.com/pricing)、[Auth0 Pricing](https://auth0.com/pricing)。

本工具提供资源估算，不代替项目技术审批、合同工期承诺或施工安全验收。
